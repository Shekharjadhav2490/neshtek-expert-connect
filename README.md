# NeshTek Expert Connect

On-demand enterprise technology consulting platform for focused 2–20 hour engagements.

## Technology Stack

- Frontend: Angular + TypeScript
- Backend: Spring Boot + Java 21
- Database: Oracle Autonomous Database
- API: REST / JSON
- Database migrations: Flyway
- Security: Spring Security
- Deployment target: Oracle Cloud Infrastructure (OCI)

## Initial Scope

1. Expert registration and onboarding
2. Minimum five technical skills per expert
3. 1,000+ word technical expertise profile
4. Availability and consulting preferences
5. Certification and document records
6. Admin review and approval
7. Customer requirement submission
8. Expert matching
9. Engagement tracking
